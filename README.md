# 产品介绍制作 Skill

版本：0.1.0 独立用户版。按确认事实制作指定产品海报、介绍页或介绍PPT/PDF及可编辑源。沿用韩叙产品方法，使用你自己的事实，不带入作者的产品、客户、价格和权益。

## 适用与边界

适合产品已经明确，需要让潜在客户快速看懂内容与参与方式的人。一次可以只处理本项，不强制跑完整商业模式或四个Skill。人群、问题或产品方向仍不清时只补会改变判断的缺口，不替你编造需求。建议、实际制造、客户采用与经营效果分别记录，不自动改价、联系客户、上架或发布。

## 准备哪些材料、怎样写

必需材料：确认的产品事实、用途/格式、品牌素材与母版；缺失事项标明待定。可以直接在对话提供，也可放在自己的工作目录，不要求固定文件名。写具体对象、时间与计量单位，区分已确认事实、已售承诺、拟议调整、测算假设及未知。
可选：现有方案、真实反馈、报价或可用母版。已经有的有效材料继续使用；缺少会改变判断的信息才补问，不凭空填成0或既有成果。

完整合成示例（仅练习，不代表真实客户或效果）：

```text
用 $hanxu-product-presentation：
请用以下合成练习事实做一份本地可编辑产品介绍页：修改范围诊断，给独立设计师；一次2小时会谈，交一份范围确认清单，含一轮清单文字修订，价格1000元/位。这是练习方案，无真实案例或销量，不写保证成交。没有头像、品牌模板和二维码，参与入口写联系提供者，不生成虚构链接。请交可打开HTML和实际预览，不上传。
```

## 安装和使用

取得完整 `hanxu-product-presentation` 文件夹后，交给能读取Skill的AI助手安装，保留配套文件。旧版与本地修改先备份到技能发现目录外，不覆盖用户任务资料。让助手读回名称、0.1.0版本和实际位置，未识别按宿主说明恢复。

安装后发送 `$hanxu-product-presentation` 和自己的材料。只处理本次要求的范围；局部返修说清改哪里、保留什么。已有有效资料不重填。结果和记录放自己的工作目录，不放安装目录。

## 包里有什么

| 文件 | 用途 | 要修改吗 |
|---|---|---|
| `SKILL.md` | 本项具体方法和工作边界 | 通常不用 |
| `references/acceptance.md` | 对照实际结果检查 | 通常不用 |
| `agents/openai.yaml` | 技能发现信息 | 通常不用 |
| `README.md`、`VERSION`、`SKILL-MANIFEST.json` | 说明、版本和文件校验 | 通常不用 |

## 会得到什么

指定介绍成品、同版本可编辑源、重要事实与未知、实际检查范围；本地成品不等于上架。交付应能直接帮助你做决定，关键判断能回到材料，具体范围与已有承诺一致；缺口与假设就近说明，不以填满表格当成解决问题。


承诺成品时必须真正生成、打开并检查导出文件，提供可编辑源；工具不足只能交文案或结构时标清阶段。纯文字材料不会被称作海报/PPT已完成。使用者指定的载体优先，PPT/PDF、位图生成按所用环境的对应工具规范制作；代码模板不能替代实际像素/逐页检查。

## 依赖、费用、验证与许可

需要可读完整Skill的AI助手及有权使用的材料，基础判断不需平台登录或额外API密钥。实际制作还需本机可用渲染/演示/文档工具与有权使用的字体、图片；缺工具据实说明，不承诺所有平台原生可编辑。模型及工具费用按自己的服务承担，不自动购买。材料由选择的AI服务处理，不自动发送客户或传入其他平台。

本版实际验证范围见 VALIDATION.md；文件检查、合成演练、真实采用和商业效果分开，不承诺普遍稳定或成交。反馈提供版本、去敏材料、具体不合理的判断，不需凭据或客户档案。

没有擅自新增开源许可证；公开可下载与再分发/转售权利分别核实。
